# Sicurezza e dati privati

Non inserire vulnerabilità, token, password, chiavi o dati personali nelle issue
pubbliche. Se disponibile, usa **Security → Report a vulnerability** su GitHub.
In assenza del canale privato, apri una issue chiedendo un contatto riservato,
senza includere dettagli tecnici sensibili o allegati.

Prima di condividere diagnosi, controlla screenshot, nomi dei giocatori, percorsi
utente, seriali ADB e contenuti dei log. Le cartelle runtime e le configurazioni
locali non fanno parte della distribuzione sorgente.

Il progetto non dichiara un programma di supporto di sicurezza o tempi garantiti
di risposta. Le segnalazioni devono indicare la versione interessata e, quando
possibile, una riproduzione che non contenga dati reali.
